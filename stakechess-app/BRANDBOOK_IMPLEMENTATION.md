## 📝 Типографика (Brandbook Principles)

### Принцип 1: "Крупная типографика"

**Правило:** Используем крупный, акцентный шрифт для быстрого донесения смысла.

#### Текущие размеры (ПРАВИЛЬНО ✅)

```css
/* Hero sections */
.text-display     → 72px (6xl) - Главные заголовки
.text-display-sm  → 60px (5xl) - Подзаголовки

/* Headers */
h1 → 48px (5xl) - Page titles
h2 → 36px (4xl) - Section titles
h3 → 24px (2xl) - Subsections
h4 → 20px (xl)  - Card headers
h5 → 18px (lg)  - Small headers
h6 → 16px (base) - Micro headers

/* Body */
.text-body-lg → 18px - Large body
.text-body    → 16px - Default body
.text-body-sm → 14px - Small text
```

#### Рекомендации по применению

**Онбординг:**
```tsx
// ✅ ПРАВИЛЬНО
<h2 className="!text-display">  // 72px - КРУПНО!
  Путь к мастерству
</h2>
<p className="text-body-lg">    // 18px
  От первого хода до гроссмейстера
</p>

// ❌ НЕПРАВИЛЬНО
<h2 className="!text-2xl">      // 24px - слишком мелко
  Путь к мастерству
</h2>
```

**Карточки:**
```tsx
// ✅ ПРАВИЛЬНО - Крупный акцент
<h3 className="!text-3xl">1450</h3>  // Рейтинг
<p className="text-body-sm">Текущий рейтинг</p>  // Метаданные

// ❌ НЕПРАВИЛЬНО
<h3 className="!text-lg">1450</h3>  // Слишком мелко
```

### Принцип 2: "Текст — главный в композиции"

**Правило:** Текст рассказывает историю. Картинки усиливают его, а не конкурируют.

#### Иерархия важности

1. **Текст** (главный) - 60-70% визуального внимания
2. **Изображения** (поддержка) - 20-30%
3. **Декор** (фон) - 10%

#### Примеры композиции

**GameResult Victory Screen:**
```tsx
✅ ПРАВИЛЬНО:
┌────────────────────────────┐
│   [Image 30% opacity]      │  ← Фон, не отвлекает
│                            │
│     ПОБЕДА!  (72px)        │  ← Главное, крупно
│     +32 рейтинга (48px)    │  ← Вторично, но заметно
│                            │
│   [Stats grid] (16px)      │  ← Детали, мелко
└────────────────────────────┘

❌ НЕПРАВИЛЬНО:
┌────────────────────────────┐
│  [HUGE Image 80%]          │  ← Доминирует
│                            │
│  Победа (24px)             │  ← Потерялся
│  +32 (18px)                │
└────────────────────────────┘
```

### Принцип 3: "Фокус на главном"

**Правило:** Главный объект — один. Остальные поддерживают его композиционно.

#### Применение в UI

**Home Page - Hero Card:**
```tsx
✅ ПРАВИЛЬНО:
Main focus: Рейтинг 1450 (display-sm - 60px)
Support:    Прогресс +50 (32px)
Details:    Побед/Поражений (18px)

❌ НЕПРАВИЛЬНО:
Всё одного размера (24px) - нет иерархии
```

**Onboarding Slides:**
```tsx
✅ ПРАВИЛЬНО:
Main: Заголовок (display - 72px) - ЕДИНСТВЕННЫЙ фокус
Support: Описание (body-lg - 18px)
BG: Image (10% opacity) - не конкурирует

❌ НЕПРАВИЛЬНО:
Заголовок (36px) + подзаголовок (32px) + текст (24px) - три конкурирующих элемента
```

## 🎨 Принципы Композиции

### 1. Не мешать всё сразу

**Выбирайте ОДИН основной приём:**

**Matchmaking Screen:**
- Главный приём: **Countdown animation** (3-2-1)
- Поддержка: Карточка соперника
- Фон: Размытый, ненавязчивый

**GameResult Screen:**
- Главный приём: **Confetti particles** (победа)
- Поддержка: Крупный текст "ПОБЕДА"
- Фон: Минимальный

### 2. Леттеринг vs Типографика

**Леттеринг** (уникальная форма):
- Используем для: Суббрендов, мерча, мероприятий
- В приложении: НЕ используем (пока)

**Типографика** (системный шрифт Inter):
- Используем для: Весь UI
- Преимущество: Читаемость, консистентность

### 3. Текст делаем крупнее

**Золотое правило:** Если текста мало → увеличивайте размер.

```tsx
// ❌ НЕПРАВИЛЬНО - Мелко для короткой фразы
<button className="text-sm">
  Начать игру
</button>

// ✅ ПРАВИЛЬНО - Смело увеличиваем
<button className="text-lg font-bold">
  Начать игру
</button>
```

## 📐 Spacing & Layout (8pt Grid)

### Вертикальные отступы

```css
/* Между секциями */
mb-8  → 32px  (стандарт)
mb-12 → 48px  (для важных разделов)

/* Внутри карточек */
p-6  → 24px  (компактно)
p-8  → 32px  (стандарт - ИСПОЛЬЗУЕМ)
p-10 → 40px  (для hero cards)

/* Между элементами в группе */
gap-4 → 16px (плотно)
gap-6 → 24px (комфортно - ИСПОЛЬЗУЕМ)
gap-8 → 32px (просторно)
```

### Пример идеальной карточки

```tsx
<div className="glass-card p-8 space-y-6">
  <h3 className="!text-3xl">Заголовок</h3>  {/* Крупно */}
  <p className="text-body">Текст</p>         {/* Читаемо */}

  <div className="space-y-4">               {/* Группа */}
    <div>...</div>
    <div>...</div>
  </div>
</div>
```

## ✅ Чеклист Compliance

Каждый новый экран должен соответствовать:

### Цвета
- [ ] Используется только #EF3124 для красного (не #FF1744)
- [ ] Фон #2A2C2F (не #0A0A0A)
- [ ] Дополнительные цвета только для спец. случаев

### Типографика
- [ ] Главный заголовок >= 48px (h1)
- [ ] Hero text >= 60px (.text-display)
- [ ] Есть четкая иерархия (1 главный, 2-3 вторичных)
- [ ] Короткие фразы → крупный шрифт

### Композиция
- [ ] Один главный элемент на экране
- [ ] Текст важнее изображений
- [ ] Изображения поддерживают, не отвлекают (opacity 10-30%)
- [ ] Не смешаны несколько приёмов одновременно

### Spacing
- [ ] 8pt grid соблюден
- [ ] Достаточно breathing room
- [ ] Группы элементов визуально разделены
