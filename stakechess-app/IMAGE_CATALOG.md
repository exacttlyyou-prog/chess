## 🎨 DESIGN PATTERNS

### Pattern 1: Hero Moments
Use large, centered images with glassmorphic overlay:
```css
.hero-image {
  width: 100%;
  max-width: 400px;
  opacity: 0.9;
  filter: drop-shadow(0 0 32px rgba(255,23,68,0.4));
}
```

### Pattern 2: Background Layers
Multiple layers for depth:
```css
.bg-layer-1 { opacity: 0.05; filter: blur(40px); }
.bg-layer-2 { opacity: 0.15; filter: blur(20px); }
.bg-layer-3 { opacity: 0.25; /* foreground */ }
```

### Pattern 3: Animated Transitions
Use motion blur images for page changes:
```typescript
<motion.div
  initial={{ opacity: 0 }}
  animate={{ opacity: [0, 1, 0] }}
  transition={{ duration: 0.4 }}
  style={{
    backgroundImage: 'url(/images/transitions/motion-blur-1.png)',
    backgroundSize: 'cover',
  }}
/>
```
