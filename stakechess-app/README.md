# StakeChess - Premium Chess App

Полнофункциональное шахматное приложение с премиум дизайном, полной реализацией правил шахмат и современным UX.

## Описание

StakeChess - это современное шахматное приложение с фокусом на красоту, удобство и актуальные тренды дизайна. Приложение включает 5 основных экранов с полной навигацией и **полностью работающей шахматной логикой**.

## Технологии

- **React 19.2** + **TypeScript 5.9** - надежная типизация
- **Vite 7.2** - быстрая сборка и hot reload
- **Tailwind CSS 3.4** - utility-first CSS фреймворк
- **Framer Motion 12** - плавные анимации и переходы
- **React Router 7** - маршрутизация между экранами
- **Lucide React** - красивые SVG иконки

## Дизайн

- **Цветовая схема**: Черный фон + алый-красный акцент
- **Стиль**: Glassmorphism + Modern Flat
- **Шрифт**: Inter
- **Адаптивность**: Mobile-first подход

## Структура приложения

### Экраны

1. **Онбординг** (`/`) - 3 свайпа знакомства с приложением + регистрация
2. **Главная** (`/home`) - Dashboard с рейтингом, статистикой и быстрыми действиями
3. **Выбор режима** (`/game-mode`) - Выбор типа игры (Блиц, Рапид, Пуля, Классика) и турниры
4. **Игровой процесс** (`/play`) - Шахматная доска с таймерами и HUD
5. **Профиль** (`/profile`) - Статистика игрока, история рейтинга, достижения

### Навигация

- Все экраны полностью кликабельны
- Bottom Navigation на главных экранах
- Плавные анимированные переходы между страницами

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build

# Превью production сборки
npm run preview
```

## Доступ

После запуска приложение доступно по адресу:
```
http://localhost:5173/
```
