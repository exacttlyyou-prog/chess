## 🎭 АНАЛИЗ ПРОЗРАЧНОСТИ/ФОНА

### Как проверить фон изображения:

```bash
# Проверка альфа-канала
identify -verbose image.png | grep -i alpha

# Проверка цвета фона
magick identify -verbose image.png | grep "Background color"
```

### Изображения, которые ТОЧНО нужно проверить на фон:

1. **Все PIECES** - должны иметь прозрачный фон
2. **HEROES** - могут иметь фон, но лучше прозрачные
3. **ACHIEVEMENTS** - трофеи должны быть без фона

### Если нужно удалить фон:

#### Автоматически (AI):
```bash
# remove.bg API
# или онлайн сервисы
```

#### Вручную (ImageMagick):
```bash
# Удалить белый фон
convert input.png -fuzz 10% -transparent white output.png

# Удалить черный фон
convert input.png -fuzz 10% -transparent black output.png
```
